# PPT 分析诊断报告

## 测试 PPT 类型
1. `sample_course.pptx` — 正常课件（有编号，8页）
2. `sample_bullets.pptx` — 知识点列表（无编号，3页）
3. `sample_mixed.pptx` — 混合型（含表格+公式，2页）

## 发现的 5 个核心问题

### 问题1: 预处理编号算法过于粗暴
**现象**: `preprocess_text()` 在无编号时给所有行加序号，包括章节标题和表格列头。
```
输入: "数据结构 — 线性表"
输出: "1. 数据结构 — 线性表"    ← 标题变成了普通项
```
**影响**: 丢失了 PPT 的结构信息 — 幻灯片标题是天然的章节标签

### 问题2: 考试总览页污染分值统计
**现象**: sample_course 最后一页"考试情况总结"包含：
```
题型分布：选择题30分 + 填空题20分 + 计算题30分 + 简答题20分
```
被归入"数据表示与运算"章节，虚增 ~100分
**影响**: 分值占比严重失真（195%）

### 问题3: 表格行被拆成独立"题目"
**现象**: sample_mixed 的 Cache 对比表格：
- 表头行"映射方式 | Cache行数 | Tag位数 | 命中率 | 硬件复杂度"变成独立块
- 4行数据各自成为独立块，每个块单独做章节匹配
**影响**: 表格的结构信息丢失，表头行容易被错分

### 问题4: 关键词歧义匹配
**现象**: 
- "邻接矩阵" → 匹配到"线性代数"（因为"矩阵"）而非"数据结构"
- "5段流水线执行100条指令" → "执行"匹配到"指令系统"而非"指令流水线"
**影响**: 部分知识点归类错误

### 问题5: 幻灯片结构信息完全丢失
**现象**: 所有幻灯片内容被拼接成一整段文本，幻灯片标题作为普通文本处理。
**PPT的真实结构应该是**:
```
[Slide Title = 章节]
  ├─ 知识点1 (分值)
  ├─ 知识点2 (分值)
  └─ 子要点列表
```

---

## 改进方案

### 核心思路: PPT 分析用专用流程，不复用 analyzer.analyze_materials()

```
PPT 文件
  ↓
extract_text_by_slide() → [(title, bullets, scores), ...]   # 保留结构
  ↓
chapter_detect_from_title() → 用标题判定章节（优先）        # 标题优先
  ↓  fallback
keyword detect → 用关键词判定（补充）                        # 关键词兜底
  ↓
aggregate_by_chapter() → 章节聚合                            # 合并同章节
  ↓
determine_raid_value() → 突击价值判定                        # 复用现有
```

### 具体修改

1. `ppt_handler.py` 改造:
   - 新增 `extract_by_slide()` 返回 `[(title, full_text, [bullet_items]), ...]`
   - `preprocess_text()` 保留幻灯片分隔符，不过度加编号
   - 新增 `extract_score_from_item()` 精确提取单个知识点的分值

2. 新增 `ppt_analyzer.py`:
   - `analyze_ppt_structure()` — 将 slide 标题映射到已知章节
   - 复用 `CHAPTER_KEYWORDS` 做 fallback
   - 对表格/公式等特殊类型做特殊处理
   - 过滤"考试总结"等非知识点页面

3. 关键词库优化:
   - "邻接矩阵" 应在"数据结构"下而非"线性代数"
   - 增加关键词的负向排除
