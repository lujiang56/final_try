使用说明
为什么要配置 LLM？
  • 上传 PPT 后自动进行语义级分析，而非简单的关键词匹配
  • 支持任意学科，不再局限于预设的科目
  • 自动生成结构化的复习笔记，包含概念讲解和解题思路
不配置也能用吗？

可以。不上传 API Key 时，系统会自动使用内置的规则引擎进行分析。LLM 分析是增强功能。

安全性
  • API Key 使用 AES-256-GCM 加密后存储在本地 SQLite 数据库
  • 所有 LLM 调用在本地服务器端完成
  • PPT 内容仅发送到你配置的 LLM Provider
